monocypher is unmodified and keeps its own (CC0/BSD-2) terms — it is **not** relicensed
under the MPL. StreamDB is DeMoD's own embedded reverse-trie database, published as a
separate LGPL project and vendored here; it likewise keeps its LGPL-2.1-or-later terms
(LGPL §3 permits conveying it under the compatible GPL-family terms; it is **not**
relicensed under the MPL).

**Steamworks boundary.** The optional Steam edition links Valve's proprietary
`libsteam_api.so`. MPL-2.0 permits combining MPL code with proprietary components in a
larger work, so this is compatible; the SDK is never committed here and is only present
in `make STEAM=1` builds. Non-Steam builds neither link nor ship it.

**HydraMesh header discrepancy (recorded, not edited).** The three headers in
`third_party/hydramesh/` are copied verbatim from the pinned upstream commit and must stay
byte-identical, so they are not edited here. Each opens with an SPDX line naming
`LGPL-3.0-only`, but the comment block of `demod_frame.h` says
`DeMoD LLC | GPL-3.0` (its siblings say `DeMoD LLC | LGPL-3.0`). The SPDX line, upstream's
licensing of its linkable C codec headers as LGPL-3.0, and this repository's use all agree on
LGPL-3.0-only, and `REUSE.toml` records the file that way; the stray `GPL-3.0` comment is
upstream's to fix, after which the pinned commit can move.

**Faust-generated code.** `apps/terminus/patches/demod-lofi-keys-mk2/.faust_cache/demod_lofi_keys_mk2_gen.cpp`
is C++ the Faust compiler generated from `demod_lofi_keys_mk2.dsp`. Faust inlined functions
from its standard libraries: `maths.lib` and `envelopes.lib` (GRAME, LGPL with the Faust
exception that lets generated code be distributed under the program's own terms) and
`filters.lib` functions by Julius O. Smith III under the MIT-style STK-4.3 licence, whose
copyright notices the file keeps in its metadata. The file is annotated as TERMINUS code
(PolyForm Shield) with those notices retained.

**Provenance assumed: the duck animation.** `apps/terminus/patches/duck-anim-frames.bin`,
`apps/terminus/patches/demod-duck-dance/duck-anim-frames.bin` (byte-identical) and their
`duck-anim-frames.lua` indexes were generated by `build-duck-anim.py` (not in this repo) from
`duck-pixel.gif` (96×96, 122 frames) and `duck-dance.mid` (160 BPM). Neither source file is in
the repository and their origin is not recorded; the pixel art may be third-party work. The
tree marks the generated files as TERMINUS code (the `.lua` index carries the PolyForm Shield
SPDX line), and `REUSE.toml` annotates them that way, DeMoD LLC. If the GIF or the MIDI file is
someone else's, these files need that owner's licence and notice, or replacement.
